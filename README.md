# 📚 Reading Coach — 阅读教练 Skill

> 教你真正读透一本书的 AI 教练。

适用于支持 Skill 的 AI 代理（如 OpenClaw、Claude Code 等），通过**反问式对话 × 知识卡片 × 深度访谈**三个阶段，帮你把书中的核心内容真正内化，并转化为可用的内容素材。

---

## 你将获得

| 产出物 | 说明 |
|--------|------|
| 🧠 **深度内化** | 通过教练式追问，真正理解书中核心概念，而不是停留在"读过了"的表面 |
| 📋 **结构化知识卡片** | 每章节自动生成 5 维度知识卡片：一句话要点、因果链、解决方案、边界条件、精华金句 |
| 🎯 **爆款内容选题** | 结合你的目标受众，从书中提炼可直接用于短视频、文章、直播的选题清单 |
| 🔍 **认知偏差纠正** | AI 主动识别你的理解偏差，当场指正并重新聚焦，不让你带着错误认知离开 |

---

## 快速入门

在 AI 代理的对话框中输入以下任意一种指令即可启动：

```
/xs-reading-coach
```

```
帮我深度阅读这本书
```

```
阅读伴侣
```

启动后，教练会引导你完成完整流程，无需额外配置。

**书籍来源支持：**
- 直接上传文件（PDF、Word、TXT 等）
- 指定已接入的知识库（如腾讯 IMA 知识库）

## 安装教程

### 前提条件
- 已安装支持 Skill 的 AI 代理（OpenClaw、Claude Code 等）

### 方法一：下载到AI代理（Open Claw/Claude Code）（推荐）
阅读 https://github.com/leacui1124/xs-reading-coach 并安装 xs-reading-coach

### 方法二：从 GitHub 安装

1. 克隆本仓库：
   ```bash
   git clone https://github.com/leacui1124/xs-reading-coach.git
   ```

2. 将文件夹复制到 AI 代理的 Skills 目录：
   ```bash
   cp -r xs-reading-coach ~/.workbuddy/skills/xs-reading-coach
   ```

3. 重启 AI 代理，在对话框输入 `/xs-reading-coach` 验证安装成功。

### 方法三：手动安装

1. 下载本仓库的 ZIP 文件，解压得到 `xs-reading-coach` 文件夹

2. 将整个文件夹移动到 AI 代理的 Skills 目录：
   ```
   ~/.workbuddy/skills/xs-reading-coach/
   ```

3. 确认目录结构如下：
   ```
   xs-reading-coach/
   ├── SKILL.md
   └── references/
       ├── card_template.md
       └── question_design.md
   ```

4. 重启 AI 代理即可使用。

## 工作原理

Reading Coach 按照 7 个步骤严格顺序执行，每个阶段各司其职：

```
第一步：确认书籍来源
    ↓ 支持文件上传 / 知识库调取
第二步：询问阅读进度
    ↓ 锁定章节范围，精准提问
第三步：反问式深度阅读
    ↓ 教练式追问，一次只问一个问题
    ↓ 偏离立刻指正，引导回归核心
第四步：生成知识卡片
    ↓ 5 维度结构化输出，存档备用
第五步：询问是否进行访谈
    ↓ 可选，适合需要产出内容的创作者
第六步：确认目标受众
    ↓ 问题针对你的受众定制，不泛泛而谈
第七步：深度访谈 → 爆款选题清单
    ↓ 每个问题都指向可直接使用的内容素材
```

### 三大核心设计原则

**1. 不直接总结，只提问**
教练不会替你总结书中的内容。它只问问题，让你自己说出答案。因为真正的内化来自输出，不是输入。

**2. 层次递进的问题结构**
问题按 5 个层次递进设计：概念澄清 → 因果追问 → 反例检验 → 迁移应用 → 整合串联，从"能背"到"能用"。

**3. 问题数量由你决定**
深度阅读环节和访谈环节的问题数量均可自定义，适配不同的时间和深度需求。
